# Evolution API - Mobile App

React Native + Expo project, scaffolded with `create-expo-app` (blank TypeScript template).

## Requirements

- Node.js 20+
- npm

## Getting started

```bash
cd mobile
npm install
npm start        # opens Expo dev tools
npm run android  # run on Android
npm run ios      # run on iOS (macOS only)
npm run web      # run in the browser
```

See the [Expo documentation](https://docs.expo.dev/) for details on building and publishing.
